# 0096 — Act from the funder–vehicle fit list

The fit list now does the three things Juan asked of it:

| | |
|---|---|
| ![The fit list, with the side pane open on a row](docs/changelog/shots/fit-0096/01-actions.webp) | The side pane on the LP in focus: score and rank, the status control, the reason, the four readings with their bases, each gate, and what the strategy proposes. |

- **Go to the LP.** The name opens the LP workspace (their page when there is no pursuit).
- **Change the status.** Each row has a status dropdown. Choosing a new status asks for a confirmation, with an
  optional line for the log. For Passed it also asks who ended it and, optionally, why. It then saves through the same
  audited path as the pipeline table's "Set status": one transaction, one idempotency key per attempt, the next step
  kept, and a refusal if the status changed since the page loaded. No rung is written, nothing is sent, and it waits
  for the server's answer before saying it saved.
- **Move with the keys.** Click a row, or move with ↑ ↓ (Home, End), and the side pane shows that LP's reading: the
  score and rank, the status control, the reason, the four readings with their bases, each gate with its answer and
  basis, and what the strategy proposes. Enter opens the LP; Esc goes back to the summary of the list.

The side pane and the list share the selected row in the browser, so moving through the rows makes no round trip to the
server. `lib/vehicle-readings` also returns the pursuit's own next step, so the pane can show it.
