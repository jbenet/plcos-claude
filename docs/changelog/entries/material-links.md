# A link on each material · 8 Oct 2026

JuanMail asked for a DocSend or file link per fund material, so a draft can carry it; Juan chose "Add link field".

The materials page has a Links card: paste an https link next to a material, or clear it. The outreach queue returns it as
`link` on each material (`null` when none). Capital OS stores the text only; it never opens the link or calls DocSend.
Setting or clearing a link is audited and needs edit access to the material's vehicle (all vehicles for a shared one).
