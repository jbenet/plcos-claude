# LPs' addresses include the ones Affinity holds · 7 Oct 2026

JuanMail found `contacts` empty on all 4,895 rows of the outreach queue, which left every draft without a recipient.
Addresses came only from research claims (a W1 finding, or an address a person confirmed from Gmail), and the addresses
Affinity holds for each person never became claims, so almost no LP had one.

Now every surface that shows an address (the queue's and the light read's `contacts`, route hops, introducers and top
connectors) also reads the addresses on the latest Affinity record of the person: the primary address first, after any
claim, each address once, `source: "affinity"`, unconfirmed. They stay R2, shown only where the reader reads words.
