# A placeholder organisation joins nobody as colleagues · 7 Oct 2026

The W5 writers found individuals sourced on 27 Sep carrying the placeholder organisation "Personal": W3 grouped them
by that name, so each had about 28 C "same firm" ties to unrelated LPs, and routes leaned on them. W3 now skips
placeholder names when it groups colleagues ("Personal", "Self", "Individual" and "(individual) …", "Private
investor", "Angel investor", "Retired", "None", "N/A", "Unknown"). Work email domains still group real colleagues.
