# A ticket's detail reads across, not apart · 8 Oct 2026

In Approvals, a ticket's "It does not authorize" and "What you are deciding on" rows put each value at the right edge,
far from its label, so a long value such as an email's evidence line was hard to read. The values now sit in a column
beside their labels and read left to right. Other cards keep their right-aligned figures.
