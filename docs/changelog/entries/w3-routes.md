# W3 routes — Recover interaction and portfolio paths

W3 1.1 reads full exported interaction history instead of only the last eight touches in
the raise window. Affinity translation resolves team participants by canonical person ID
as well as email and retains outbound senders. Contact paths project onto LP firms.

The local portfolio snapshot now supplies sourced founder paths, including non-LP connectors
with evidenced onward relationships. Exclusions and ambiguous identities stay separate.
Documented direct conversations keep at least B while warmth still ages; group attendance
stays C. PL membership stays C and names a recorded relationship holder when available.

Invented properties cover historical meetings, both interaction sources, person-ID/email
participants, outbound emails, firm projection, portfolio founders, podcasts and membership
explanations. No real records were read. Live recovery requires a fresh translation/export
and W3 rerun by the integrator; see `docs/workflows/w3-connect.md`.

Validation: `npx tsc --noEmit`, `npm run boundaries`, `npm run props` (PGlite).
Postgres validation remains at merge.
